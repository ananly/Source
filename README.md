# 专属动漫 TVBox / 影视仓 源

聚合 8 个 MacCMS 资源站的动漫分类，纯动漫内容、原生卡片体验、m3u8 直链播放。

## 功能

- **分类**：今日追番 / 热播榜 / 最新收录 / 国产动漫 / 樱花动漫 / 欧美动漫 / 动漫剧场
- **详情跨站聚合**：点开一部番，自动合并多个资源站的同番线路，按「无广告 → 有广告」固定排序，手动切换
- **无广告站优先**：量子 ✅ / 360 ✅ / 暴风 ✅ / 最大 ✅ / ikun ✅ / 速播 ⚠️ / 索尼 ⚠️ / 如意 ⚠️
- **搜索**：8 站并发搜索，自动清洗年份/季数提高命中率

## 导入

**在线托管（推荐）**

```
https://cdn.jsdelivr.net/gh/ananly/Source@main/anime.json
```

GitHub Raw 备用：

```
https://raw.githubusercontent.com/ananly/Source/main/anime-github.json
```

**本地使用**：把 `spider.py` 放到手机 `Download/`，导入 `anime-local.json`。

## 文件

| 文件 | 说明 |
|---|---|
| `spider.py` | 源本体（Python，type=3） |
| `anime.json` | 托管配置（CDN 地址） |
| `anime-github.json` | 托管配置（Raw 地址） |
| `anime-local.json` | 本地配置 |
| `anime-min.json` | 极简配置 |

## 说明

- 广告是资源站转码时烧录的画面水印，换线路只能减轻无法根除；本项目按实测把无广告站排前面。
- 番剧类目前全网最高画质即 1080P，无 4K 片源。
